# Documentation

gatewizz is a local HTTPS proxy for Windows developer tools. This directory contains the operational reference; project scope and engineering decisions remain in [PLAN.md](../PLAN.md).

## Guides

- [Reference](REFERENCE.md): installation commands, configuration, rule evaluation, HTTPS interception, local CA, approvals, event privacy, tool integration, build, CI and known limitations.
- [Example configuration](../config/gatewizz.example.toml): all optional settings with defaults and rule examples.
- [Engineering plan](../PLAN.md): goals, non-goals, engineering rules, architecture and milestone status.
- [GitHub Releases](https://github.com/mycaravam-crypto/Gatewizz/releases): Windows x64 binaries and checksums.

Start with the [README](../README.md) for installation and a quick start.
